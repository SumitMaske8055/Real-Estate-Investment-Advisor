# Real-Estate-Investment-Advisor
A machine learning project that predicts property profitability and future value using 250,000 Indian housing records. Implements both classification (Good Investment?) and regression (5-year price forecast) using Random Forest and Logistic/Ridge Regression — achieving 99.92% accuracy and R² of 0.9997.
